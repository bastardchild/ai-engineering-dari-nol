AI Engineering dari Nol

Sumber daya developer

Ini adalah titik masuk yang dapat dibaca mesin untuk AI Engineering dari Nol. Kurikulum ini statis dan bersumber terbuka, dengan API representasi hanya-baca untuk agen dan alat developer. Mulai dengan llms.txt, yang memetakan pelajaran ke halaman kanonik dan sumber Markdown mentahnya.

Sumber daya stabil

  • /llms.txt adalah peta kurikulum yang berorientasi agen.
  • /sitemap.xml mencantumkan URL publik kanonik.
  • /openapi.json menjelaskan permukaan sumber daya hanya-baca.
  • /api/v1/markdown menyajikan HTML atau Markdown untuk halaman navigasi publik yang dipilih oleh parameter kueri path.
  • /catalog.html adalah katalog manusia yang dapat dicari.
  • GitHub adalah sumber kebenaran untuk pelajaran, kode, kuis, dan artefak yang dapat digunakan kembali.

Negosiasi Markdown

Permintaan untuk beranda atau rute navigasi utama dengan Accept: text/markdown menerima peta agen dengan Content-Type: text/markdown. Respons bervariasi berdasarkan Accept sehingga cache tidak dapat mencampur representasi HTML dan Markdown.

API representasi menerima GET dan HEAD. Respons menyertakan X-API-Version: 1; HEAD mengembalikan metadata yang sama tanpa body. Representasi dan metode yang tidak didukung menerima detail masalah RFC 9457. Halaman yang tidak ditemukan tetap menyediakan tautan pemulihan HTML atau Markdown untuk pembaca dan agen, dengan detail masalah untuk klien API lainnya.

/api/markdown tetap menjadi alias yang kompatibel. Perubahan aditif tetap berada di bawah /api/v1/markdown; perubahan representasi yang merusak memerlukan jalur berversi baru. API tidak menerbitkan header kuota karena tidak menerapkan pembatasan laju per klien.

Status MCP

Situs web saat ini tidak menyediakan server MCP yang dihosting atau API produk yang terautentikasi. Kurikulum memang mengajarkan cara membangun dan mengoperasikan server MCP, dan artefak pelajaran tersebut berada di repositori. Endpoint MCP Streamable HTTP jarak jauh akan memerlukan keputusan produk, kebijakan autentikasi, dan pemilik operasional yang terpisah.
